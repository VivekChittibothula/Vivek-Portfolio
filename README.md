## The idea

This portfolio is intentionally small. It gives the work room to breathe, keeps the interface fast, and lets a few well-placed interactions do the talking.

The visual language is inspired by the restraint of Apple product pages: system typography, generous spacing, soft surfaces, and motion with a reason behind it.

## Built with

`HTML` · `CSS` · `Vanilla JavaScript` · `FormSubmit` · `GitHub Pages`

No framework, build step, or unnecessary dependency. The site is a lightweight static experience that can be opened directly or served from any static host.

## What is inside

- Light and dark moods with preference persistence
- Pointer-responsive hero mark
- Smooth, CSS-based infinite marquee
- Reduced-motion support and keyboard-visible focus states
- Opt-in interface sound effects with safe playback handling
- Selected work, skills, certifications, and contact sections
- AJAX contact form with labeled name, email, and message details
- Responsive layout tuned for small screens first

## Run it locally

```bash
git clone https://github.com/VivekChittibothula/Vivek-Portfolio.git
cd Vivek-Portfolio
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

Opening `index.html` directly also works, but a local server gives the most accurate browser behavior for assets and form requests.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will publish the site at:

`https://vivekchittibothula.github.io/Vivek-Portfolio/`
